# README assets (visuals)

Optional files to make the repo **more discoverable** (stars follow **clarity + motion**).

| File | Purpose |
|------|---------|
| **`banner.svg`** | Default wide banner (vector). Linked from root README. Replace anytime. |
| **`hero.webp`** or **`hero.png`** | **Nano Banana** / Gemini / Imagen-class **still** — hero image for social previews (add when ready). |
| **`demo.mp4`** or **`demo.webm`** | **~15–30s screen capture** or **Veo**-style clip: MCP in Cursor + dashboard + Fleet onboard. Host on repo **Releases** or embed GIF in README if video is heavy. |

**Honest tip:** a **single sharp GIF** in the README often beats a silent MP4 for GitHub scrollers.

After adding binaries, reference them from the root **[README.md](../../README.md)** (e.g. `![Demo](docs/assets/demo.gif)`).
